## 不可绕过的安全门槛

| 操作类别 | 强制规则 |
| --- | --- |
| SSH 连接 | 必须匹配已确认的 SHA-256 主机指纹；禁止 `StrictHostKeyChecking=no` 等自动接受模式。 |
| 任意终端命令 | 必须提交“执行 SSH 终端命令”的单次确认；内置管理命令只能经受限目录构建。 |
| 网络、无线、防火墙、固件与快照恢复 | 必须选择快照并准确输入操作确认文本。 |
| 文件写入、删除、软件包变更 | 必须经过相应 `OperationApproval` 验证。 |
| 本地持久化 | 只保存档案元数据、已确认主机指纹与脱敏审计记录；不得写入密码、私钥、令牌或 cookie。 |

## 发布验收基线

目前本地验收包括 `cargo fmt --check`、`cargo check --workspace`、`cargo test --workspace`、`cargo run -p openwrt-cli`、非 pedantic 严格 Clippy 以及 ARM64 Android AAB 打包。GitHub Actions 对 `Rust-Dev` 的最新提交执行相同工作区检查与 ARM64 AAB 归档。
