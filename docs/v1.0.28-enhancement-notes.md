# v1.0.28 管理功能兼容性记录

固件升级仅接受 `.bin` 与 `.img` 文件。镜像上传到路由器后，应用先执行 `sysupgrade -T` 完成设备端校验；只有校验成功，才允许用户在确认弹窗中选择是否保留当前配置并提交 `sysupgrade`。

硬件详情的温度采集兼容 OpenWrt 的 IEEE 802.11、thermal zone 和 hwmon 路径。识别为无线芯片的 hwmon 名称归入 WiFi 温度，其他热区与 hwmon 温度归入系统温度，界面分别显示可用值。

APK 仓库快照会读取 `customfeeds.list`、`distfeed` 及兼容的 `distfeeds.list`，并保留每个非空配置行的来源文件、行号和启用状态，以供完整展示和安全写回。
